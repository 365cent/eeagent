## Update rule

When an input arrives, record the named provider, actual receipt date, exact version or checksum, permitted use, storage location, reviewer, and affected acceptance IDs. Keep absent values as “not recorded”; do not infer an owner, date, license, or approval from a filename, meeting note, or implementation assumption.
