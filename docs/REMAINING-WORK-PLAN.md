## 1. 完成定义

一个父任务只有同时满足以下 5 条才从 TODO 移除：

1. 子系统 TODO「验收」段落中的每一条都有对应实现。
2. 有自动化用例或可复现的人工步骤；失败路径同样有覆盖。
3. 证据写入 [DELIVERY-RECORD.md](DELIVERY-RECORD.md)：版本、环境、命令/步骤、结果、截图或日志、未通过项。
4. [REQUIREMENTS-TRACEABILITY.md](REQUIREMENTS-TRACEABILITY.md) 中对应 AT 由「待验」改为「通过」，并链接证据。
5. 复核人签字（角色即可，具体人名由 DOC-02 登记）。

不满足第 2/3 条的实现切片叫"已交付切片"，不叫"已验收"。开发机 macOS/Windows 结果不能替代 Linux 服务或 Windows 业务机结果。

## 9. 并行重构车道

- 每片先加/改测试，再做行为等价的搬迁；测试必须同一提交内通过。
- 独立提交，不与功能修改混合；每片都能单独回退。
- BE-17 每片保持 `lint-imports` 与 OpenAPI 路径快照不变；FE-13 每片保持 URL、主题 token 与 re-export；CC-07 保持幂等与重试语义。
